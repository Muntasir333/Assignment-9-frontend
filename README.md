# Purpose

SportNest is a sports facility booking platform that allows users to discover, book, and manage sports facilities easily. Facility owners can add, update, and manage their venues, while users can browse available facilities and make bookings through a secure and user-friendly interface.

# Live URL
https://sportnest-eosin.vercel.app/

# Features
User authentication and protected routes
Add, update, and delete sports facilities
Book sports facilities online
Manage personal facilities and bookings
Search and sort facilities efficiently
Responsive design for mobile, tablet, and desktop devices
Secure API access using JWT authentication
